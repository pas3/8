# Bashir Electronic – Stability Edition

**Supported PS4 firmware versions in this package**

- 6.72
- 9.00, 9.03, 9.04, 9.50, 9.51, 9.60
- 10.00, 10.50, 11.00, 11.02
- 11.50, 11.52
- 12.00, 12.02, 12.50, 12.52
- 13.00, 13.02, 13.04, 13.50, 13.52
- 14.00, 14.02

The launcher checks the PS4 firmware string and only selects a route represented by local project assets. Firmware 5.05, 7.xx, and 8.xx are not included in the supported routes.
